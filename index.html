조작법 & 시스템

조작

  • ↑ / W 가속 · ↓ / S 브레이크·후진
  • ← → / A D 조향
  • Shift / Z 드리프트 (홉 후 유지)
  • Space / X 아이템 사용
  • Esc 일시 정지

주행 테크닉

  • 미니 터보 드리프트 유지 → 파랑▸주황▸보라 스파크, 해제 시 단계 비례 부스터
  • 슬립스트림 앞차 바로 뒤 밀집 구역에서 1.15초 주행 시 순간 가속
  • 로켓 스타트 카운트다운 "2" 직후부터 가속 입력 유지
  • 부스터 발판 노란 화살표 위를 통과

피격 상태(FSM)

  • Spin-out 바나나·초록 껍질 → 추진력 0, 720° 회전 1.5초
  • Knockback 폭탄·가시 껍질 → 공중 임펄스 + 아이템/동전 드롭
  • Shrink 번개 → 0.5배 축소, 5초간 40% 감쇄, 아이템 파괴
