# 🏁 SUPER KART GRAND PRIX

브라우저에서 바로 실행되는 마리오 카트 스타일 레이싱 게임.
빌드 도구·의존성 없이 순수 HTML5 Canvas + Vanilla JS로 작성했습니다.

`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.
(로컬 서버로 띄우려면 `npx http-server -p 8080` 후 http://localhost:8080)

---

## 구현 범위

### 1. 캐릭터 & 카트 조합 물리 스탯 시스템

**체급별 캐릭터 데이터 구조** (`js/data.js`)

| 체급 | 캐릭터 | 성향 |
|---|---|---|
| 경량급 | 키노피오, 베이비 마리오, 피치 | 가속·핸들링·오프로드 마찰 高 / 최고속 低. 피격 회복도 가장 빠름 |
| 중형급 | 마리오, 루이지, 요시 | 속도·가속·핸들링·무게 균형 |
| 중량급 | 동키콩, 쿠파 | 최고속·무게 最上 / 가속·핸들링 最下 |

**파츠 합산** (`js/stats.js`)

```
최종 스탯 = [캐릭터 Base] + [카트 프레임] + [바퀴] + [글라이더]
합산 스탯 = 최고속(speed) · 가속(accel) · 무게(weight) · 핸들링(handling) · 오프로드 마찰(offroad)
```

합산된 0~10 스케일 스탯은 `Stats.toPhysics()`에서 실제 주행 물리 제어 값으로 변환되어
매 프레임 적분에 사용됩니다.

| 물리 제어 값 | 산출식 | 용도 |
|---|---|---|
| `mass` | `62 + weight × 17` | 카트 간 충돌 밀어내기, 관성 |
| `inertia` | `0.55 + weight×0.06 − handling×0.02` | 회전 관성(조향 반응 둔화) |
| `maxTorque` / `accelRate` | 가속 스탯 기반 | 엔진 토크 → 가속도 |
| `maxSpeed` | `296 + speed × 25` | 최고 속도 |
| `tireFriction` / `driftFriction` | 핸들링 기반 | 타이어 횡마찰 계수 |
| `offroadGrip` | `0.34 + offroad × 0.049` | 오프로드 최고속 배율 |
| `recoverScale` | 가속 스탯 반비례 | 피격 후 회복 속도 |

파츠 6종 프레임 · 5종 바퀴 · 4종 글라이더 = **8 × 6 × 5 × 4 = 960가지 조합**.

### 2. 순위 기반 아이템 드롭 가중치 알고리즘 (`js/items.js`)

아이템 상자와 충돌하면 **그 순간의 실시간 순위(1~8위)** 로 확률 테이블을 조회합니다.

| 순위 구간 | 배정 성향 | 주요 아이템 |
|---|---|---|
| 1위 | 방어 / 트랩 | 바나나, 초록 껍질, 동전 |
| 2~3위 | 견제 / 단거리 추격 | 빨간 껍질, 버섯, 초록 껍질 |
| 4~6위 | 역전용 이동기 / 범위기 | 트리플 버섯, 폭탄병, 킬러, 스타 |
| 7~8위 | 광역 / 특수 고확률 | 가시 껍질, 번개, 킬러, 스타 |

**룰렛 연출**: 획득 즉시 가중치 알고리즘으로 결과를 확정하되, 1.5초 동안 아이콘을
무작위로 회전시키고(끝으로 갈수록 감속) 연출 종료 직전 최종 아이템을 슬롯에 장착합니다.
참가자가 8명 미만이면 최하위가 테이블 끝에 닿도록 순위를 정규화합니다.

### 3. FSM 기반 피격 반응 (`js/kart.js`)

| 상태 | 트리거 | 동작 | 복귀 |
|---|---|---|---|
| `NORMAL` | — | 입력(가속/브레이크/드리프트)에 정상 반응 | — |
| `SPINOUT` | 바나나 · 초록 껍질 | 전진 추진력 **즉시 0**, Y축 **720° 회전** | 1.5초 후 가속도 0부터 재상승 |
| `KNOCKBACK` | 폭탄병 · 가시 껍질 · 쿵쿵이 | 수직/수평 **임펄스**로 공중에 떠서 회전하며 튕겨나감. **소지 아이템·동전을 필드에 강제 드롭** | 착지 후 회복 단계(체급별 `recoverScale`) → `NORMAL` |
| `SHRUNK` | 번개 | 사용자를 제외한 전원 **스케일 0.5배**, 최고속·가속 **40% 감쇄**, 소지 아이템 즉시 파괴 | 5초 (마지막 0.5초 동안 크기 복원) |
| `RESPAWN` | 코스 이탈 · 허공 추락 · 용암 | 라키투가 중심선으로 복귀시킴 | 1.4초 |
| `BULLET` | 킬러 사용 | 무적 자동 주행, 접촉한 상대를 스핀아웃 | 4.6초 |

드롭된 동전은 실제로 필드에 흩어져 다른 카트가 주워갈 수 있습니다.

### 4. 로비 & 대시보드 (`js/lobby.js`)

* **파츠 커스텀 탭** — 캐릭터 / 프레임 / 바퀴 / 글라이더 4개 탭, 각 카드에 해당 조합의 미니 프리뷰 렌더
* **스탯 바** — 5개 스탯을 게이지 + 수치로 표시. 파츠를 바꾸면 즉시 재계산되며 **상승/하락이 색으로 구분**
* **3D 프리뷰** — 선택한 조합을 실시간 회전 렌더 (절차적 3D 박스 렌더러)
* **아이템 룰렛 시뮬레이터** — 순위 슬라이더(1~8위)로 확률 테이블을 확인하고, 실제 게임과 동일한 가중치·연출로 뽑기 테스트
* **트랙 선택 카드** — 난이도(★)·랩 수·설명이 담긴 투표 카드, 썸네일은 제어점에서 실시간 생성
* **파티 룸** — 8슬롯 아바타 / 카트 조합 스펙 / READY·WAITING 색상 태그 / 핑(ms) 표시, 전원 READY 시 `GAME START` 활성화

### 5. 주행 연출 & 서브 시스템

* **드리프트 & 미니 터보** — 드리프트 유지 시간에 따라 **Blue ▸ Orange ▸ Purple** 3단계 스파크,
  해제 시 단계 비례 부스터 (0.55s×1.20 / 0.85s×1.32 / 1.20s×1.46)
* **슬립스트림** — 앞차 뒤 밀집 구역(전방 30~230, 좌우 46 이내)에서 1.15초 주행 시 기류 연출 후 순간 가속
* **로켓 스타트** — 카운트다운 "2" 직후 가속 입력 시 부스터, 너무 이르면 엔진 과부하로 출발 지연
* **동적 카메라** — 속도·부스터에 따라 FOV(초점거리)와 카메라 거리가 가변, 피격 시 화면 흔들림
* **HUD** — 실시간 전체 순위표, 미니맵, 랩/총 타임, 아이템 슬롯(룰렛 연출), 속도계, 동전, 드리프트/슬립스트림 게이지

### 트랙

| 트랙 | 난이도 | 특징 |
|---|---|---|
| **마리오 서킷** | ★ | 아스팔트 + 흰·빨강 체크 커브 둔턱, 잔디 오프로드. 배경에 피치 성·토피어리 뻐끔플라워·깃발 흔드는 관중석 |
| **무지개 로드** | ★★★ | 육각 프리즘이 각인된 무지개 유리 도로, 펜스 없는 우주. 토성의 띠·회전하는 별 소행성, 네온 부스터. 이탈 시 추락 |
| **쿠파 성** | ★★★ | 금이 간 용암 석판 도로(틈새 마그마), 좌우 용암 폭포, 내려찍는 쿵쿵이. 갓길 밖은 용암 |

트랙은 Catmull-Rom 스플라인 제어점에서 **절차적으로 생성**됩니다.
2048px 비주얼 텍스처(렌더링용)와 1024px 서페이스 맵(노면 물리 판정용)을 같은 지오메트리로
동시에 구워, 보이는 그대로 물리 판정이 이뤄집니다.

## 렌더링

펜스 없는 개활 트랙을 표현하기 위해 **Mode-7 방식의 의사 3D 렌더러**를 직접 구현했습니다.

1. 지평선 아래 각 스캔라인에 대해 카메라 높이·초점거리로 월드 거리를 역산
2. 스캔라인마다 텍스처 샘플링 시작점과 픽셀당 증분을 구해 `Uint32Array`에 직접 기록 (아핀 샘플링)
3. 거리에 따른 안개(fog) 블렌딩으로 깊이감 부여
4. 카트·아이템·장식물은 같은 투영식으로 배치되는 **빌보드**로, 깊이 정렬 후 오버레이

카트 스프라이트는 외부 이미지 없이 로컬 3D 좌표(면 단위 깊이 정렬 박스 렌더러)로
**24방향 빌보드를 로딩 시 미리 구워** 사용합니다. 아이템 아이콘도 전부 절차적으로 그려
이모지 폰트 유무와 무관하게 동일하게 보입니다.

1280×720 기준 60 FPS로 동작합니다.
